# AX Module Studio Orchestrator

Python LangGraph coding-agent runtime repository for AX Module Studio.

## Current state

This is the governance-only owner bootstrap. Python packages, lock files, runtime source, Docker assets, and agent graphs have not been created yet.

The LangGraph runtime is mandatory for coding-agent use, integration testing, and the final demonstration, but implementation begins only after the approved Stage 0 contract work.

## Workflow

Normal changes use `latest dev -> feature/<work-slug> -> pull request to dev`. Direct pushes to `dev` and `main` are reserved for explicitly approved owner bootstrap or emergency recovery.
